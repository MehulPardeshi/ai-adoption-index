# team/: one profile per person

Each teammate creates **their own file** here (`team/<first>-<last>.md`, copied from [`_TEMPLATE.md`](_TEMPLATE.md)) and opens a pull request. One file per person means no merge conflicts.

Your profile holds:
- **Your proposed role**, picked from the menu in [`memory/01-team-and-roles.md`](../memory/01-team-and-roles.md). It stays *proposed* until the team's majority vote, which gets logged in [`memory/09-decisions-log.md`](../memory/09-decisions-log.md).
- **Your GitHub username and a short bio.** The final README (TP3) needs an author list with GitHub links and "a proper bio".
- **What you'll work on first, and your questions for the client.**

The shared tracker's **Roles** tab mirrors this folder.
