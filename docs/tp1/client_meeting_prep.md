## The problem as we understand it
Financial-services firms talk about AI constantly, but there is no systematic, public measure of *how* and *how much* they actually adopt it, especially among the retirement plan providers and recordkeepers that matter for the chapter. The brief asks for:
- an index built only from legally accessible public sources (SEC EDGAR filings, earnings-call transcripts, press releases, news);
- a taxonomy of AI use cases derived from real documents;
- metrics such as mention density, specificity and sentiment, combined into a quarterly, firm-level index with 8–12 quarters of history;
- an interactive dashboard with cited evidence.

**Our central concern:** *mentioning* AI in a filing is not the same as *using* it. The index must separate concrete, deployed applications from generic or forward-looking talk.
